# Proof loop — nex-robotix

**Live:** https://nex-robotix.noaerth.com  
**Claim level:** DEMO unless marked PROVEN in `startupjourney.md`.

## Fastest validation (under 30 minutes)

1. Run `pnpm dev` and complete one primary user action with sample data.
2. Capture one screenshot or export of the result.
3. Write one sentence: what a real user would pay for (or why not yet).

## Success criteria

| Signal | Target |
|--------|--------|
| Time to first result | Under 3 minutes from landing |
| Output clarity | User can explain result without you |
| Trust | Demo labels visible; no fake traction |

## What would upgrade proof level

- **Build proof:** green `pnpm build` on clean install
- **User proof:** 1 external person completes flow unaided
- **Revenue proof:** paid pilot or LOI (document privately)

## Do not claim yet

- Production scale, compliance certification, live customer counts, or revenue unless PROVEN.
